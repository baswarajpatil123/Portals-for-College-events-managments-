# Portals-for-College-events-managments-

#the setup

-firstly install mysql 

-then install all things from requirements.txt 

-run the server in one shell

-open the portal using http://localhost:5000/admin-portal  in browser

#the system implementation

-mostly python and javascript is used in backend with mysql query for database managements

-the flask is used for main application routing and html,css for frontend

-students can register for events and check event details and give feedback

-admin can get some analytics and do all operations on event creation, cancellation etc
